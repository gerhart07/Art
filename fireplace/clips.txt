# Fireplace clips. One clip per line:   file or link | name | tags
#
# To add your own clip:
#   1. Upload the video file into the "fireplace/clips" folder on GitHub.
#   2. Add a line below, like:   clips/rainy-cabin.mp4 | Rainy cabin | rain, night
# The name and tags are optional. A full web link to a video file works too.
#
# Tags pick when a clip plays. The page changes clips every 10 minutes and prefers ones that fit today.
#   Season:   winter, spring, summer, fall      (the clip only plays in that season)
#   Holiday:  christmas, newyear, thanksgiving, halloween, valentines, july4   (only plays then, and comes first then)
#   Weather:  clear, cloudy, fog, rain, snow    (comes first when the weather in Brea matches)
#   Time:     day, night                        (a small nudge toward the right time of day)
# A clip with no tags fits any day.
# Lines that start with # are notes and are skipped.
