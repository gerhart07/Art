# Fireplace clips

Put video files for the fireplace page in this folder, then list each one in `../clips.txt`. Tags there (like `rain, night` or `christmas`) decide when it plays; the notes at the top of that file list them.

- Best shape: tall (portrait), 1080 x 1920. Wide clips work too; the page crops them to fill the screen.
- Best format: MP4 (H.264). Keep each file under about 50 MB so it loads fast on the TV.
- Clips in this folder repeat as they are, so each one should loop seamlessly. Send me a raw clip and I trim it, fade its end into its start, drop its sound and size it for the TV. Clips linked from other sites dip softly to dark when they repeat.
- If a clip has its own sound, it plays muted. The crackle in `clips.txt` plays under every clip.

- cat-by-the-stove.mp4: made by Garrett in Google Flow, looped and sized here.
